# Students-Record-Management-system
Student Record Management System is a menu-driven Mini Project-II developed in C Programming using Singly Linked List, Dynamic Memory Allocation, Modular Programming and File Handling to efficiently manage student records containing Roll Number, Name and Percentage, where each student is stored as a dynamically allocated node and the system provides options to Add a new record with auto-generated unique Roll Number, Show all records in tabular format, Delete a record by Roll Number or Name, Modify a record by Roll Number, Name or Percentage, Save records to student.dat file with automatic loading on startup, Sort records by Name in alphabetical order or by Percentage in descending order, Delete All records with proper memory freeing, Reverse the linked list, and Exit with Save and Exit or Exit Without Saving, making it a complete practical implementation of linked list operations, searching, sorting, reversing and file handling in C.
